# 首版由平台托管生成应用

最新决定：用户选择免费部署平台，暂不启用公开应用托管。本决定的实现保留，当前范围以 [0008](0008-free-render-launch.md) 为准。

当前细化：生成应用是浏览器执行的单个 HTML；用户允许将已发布 HTML 及可选预览数据上传至托管空间。平台会在 Render 部署，托管空间只保存发布产物及其管理凭证哈希，不保存聊天、模型密钥或历史版本。

为了实现用户点击发布即可获得独立访问链接，首版选择由平台承担生成应用的托管，而不是要求每位用户先连接自己的服务器或第三方托管账户。这要求交付包含实际的应用运行、持久数据和发布管理能力；具体托管服务、资源生命周期与付费方案尚未确定，不能以仅导出代码代替发布。
