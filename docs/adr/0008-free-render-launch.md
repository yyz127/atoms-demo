# 免费部署平台，暂缓公开应用托管

用户明确选择先免费部署平台，不启用公开应用托管。默认 render.yaml 使用 Free Web Service，无磁盘、无数据库。Python 代理不保存工作空间数据；生产环境的公开发布入口和接口同时禁用，HTML 导出仍可用。

平台允许服务闲置休眠，接受再次访问的冷启动。定时任务仅在浏览器页面打开时执行，浏览器本地数据不依赖服务文件系统。

render-persistent.yaml 仅保留为未来方案，不在本次授权中使用。当前仍需 Render 连接与可用源码入口才能实际部署，配置完成不代表上线。
