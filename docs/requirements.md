# 当前需求（以用户最新决定为准）

状态：最新需求改为邮箱与密码注册登录，不发送邮件验证；密码方案上线状态以实际部署结果为准。

## 平台

- React Web 工作台通过 Python 认证与数据接口使用一套 PostgreSQL；账号、对话、文件夹、版本、研究、模型配置、运行记录及通知按用户隔离并跨浏览器读取。
- 支持邮箱密码注册及登录，不验证邮箱归属；密码只保存加盐哈希，旧账号须使用已登录会话设置密码；服务端加密保存模型 Key，不能向浏览器返回已有明文。
- 游客工作空间独立保存在本地；旧记录迁移须先预览和确认，不自动覆盖云端。生成应用的业务数据仍仅存访问者浏览器。
- 对接 OpenAI、Anthropic、DeepSeek、通义千问、Kimi，以及自定义 HTTPS API 地址和模型名称；用户提供自己的 API Key。
- 普通模式直接生成并预览；Plan and Execute 模式先生成可编辑计划，确认后执行。支持停止、真实错误提示、最多 3 次自动修复。
- 每轮产生新代码形成版本，保留历史并支持恢复；代码回滚不重置预览数据。
- 文件夹组织多条对话，每条构建对话拥有独立应用与版本。研究报告可以供其他对话引用。

## 生成应用

- 自然语言生成的产物统一是一个 HTML 文件，内联 CSS 和 JavaScript。
- 生成应用无账号、无后端数据库，业务记录通过 LocalStorage 保存。
- 工作台可切换代码与真实预览，历史记录以弹窗展示。
- 一键下载当前选中版本 HTML，可选带预览数据或空模板；导出文件可以独立打开，不带平台模型密钥和聊天记录。
- 项目页提供应用卡片、全部/已收藏、打开、克隆、复制链接、取消发布、删除，不提供隐私控制开关。
- 克隆仅复制当前选中版本源码与非敏感配置，创建独立应用和空的新对话；不带原聊天、历史、业务数据、应用用户、密钥或发布链接，默认未发布。
- 删除前确认并下线，项目及对应对话进入可恢复回收站；永久删除再次确认。取消发布仅停止公开访问，保留本地项目和数据。

## 研究与发布

- 真实搜索并读取公开网页，报告带来源与局限，支持 Markdown 导出和用于后续构建。
- 平台最终部署到 Render，并交付经过验证的在线访问链接。
- 用户允许将发布的 HTML 及可选预览数据上传托管空间；聊天、密钥、历史版本不进入公开产物。访问者后续操作保存于各自浏览器。
- 固定发布链接指向显式发布版本；新版本须再次发布才更新，取消发布即停止访问。
- 用户已选择首版免费部署平台，暂不启用公开应用托管。默认 render.yaml 不创建磁盘或付费资源；发布按钮与接口禁用，HTML 导出保留。
- 长期公开托管作为后续能力保留实现，需要另行决定资源方案。免费 Web Service 和账号方案已部署；当前不发送验证邮件。
