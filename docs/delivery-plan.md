# 最终交付方案与实现状态

本文件按最后一次需求调整重写。当前架构为 **React 平台 + 无数据库 Python 代理 + LocalStorage**，生成产物为 **单个 HTML**。完整当前需求见 [requirements.md](requirements.md)。

## 使用流程

1. 打开首页，在“设置与模型”添加自己的厂商、API 地址、模型名称和 API Key，明确点击连接测试验证。
2. 输入需求，选择构建、先做计划或深度研究。普通模式直接生成；计划模式先编辑并确认计划。
3. 左侧对话持续迭代，右侧切换代码和真实预览。每轮生成保存版本；失败版本不替换上一可用版本，语法错误最多自动修复 3 次。
4. 点击历史记录查看版本弹窗，恢复旧代码后继续构建。恢复代码不覆盖已有预览数据。
5. 导出当前版本，选择“空模板”或“带预览数据”，下载一个可独立打开的 HTML。
6. 当前免费上线范围暂不提供公开应用托管，可导出 HTML；发布与可选公开预览种子的实现保留供后续启用。

## 界面与项目组织

- 清新浅色界面、柔和紫色强调；桌面侧栏和对话/预览双栏，窄屏切换工作视图。
- 首页需求输入、项目卡片、全部/收藏筛选、研究报告、定时任务、回收站、模型与本地数据设置。
- 文件夹组织对话，每条构建对话有独立应用、代码版本和预览数据。
- 卡片支持打开、克隆、复制链接、重命名、移动文件夹、取消发布和移入回收站。
- 克隆建立独立应用和空对话，只复制选中版本代码，不复制记录、密钥、发布权限或历史。
- 未发布的工作台定位链接仅能定位当前浏览器已有记录，不是跨浏览器分享；发布链接才可对外访问。
- 取消发布保留本地项目和数据。删除项目先尝试下线，再进入回收站；下线失败会提示而不谎报完成。恢复后不自动发布，相关定时任务保持暂停。

## 单文件与数据隔离

- 原始版本仅保存 index.html 文本，HTML、CSS、JavaScript 均内联，业务数据用标准 LocalStorage 方法。
- 生成脚本在不具备 allow-same-origin 的 sandbox iframe 中执行，不能直接读平台密钥与聊天。
- 限定的消息桥只接受对应预览 iframe 的数据变更，将它保存到当前应用的独立本地数据映射。
- 独立导出的 HTML 包含内联的存储适配器：保存到自己的 LocalStorage 命名空间，并按选择注入预览种子或空数据。不会访问平台接口，也不需要安装依赖。
- 应用初始业务记录为空，不通过伪造演示数据冒充用户记录。
- 平台数据存储失败会提示，不能将未保存的变更假装成功。
- 备份可默认不含模型 API Key；备份包含本地项目的发布管理权限，应按敏感文件保管。导入需明确确认替换当前工作空间。

## Python 服务

- 处理 /api/test 与 /api/run：请求携带本次选用的模型配置，服务端不保存密钥、聊天或任务状态。
- OpenAI 兼容协议覆盖 OpenAI、DeepSeek、通义千问、Kimi 及自定义地址；Anthropic 使用 Messages 协议。
- 流式返回阶段、内容、来源、HTML 产物和真实错误。浏览器断开时取消服务端本次请求。
- 网页检索可配置 SearXNG，默认使用公开搜索与备用链路；只将实际取得的资料用于报告，无法取得资料时明确失败。
- 外部访问校验 HTTPS 公网地址，校验 DNS 并固定连接 IP 与 TLS 主机名；不允许读取本机或私网地址。
- 本地 VPN 若合成非公网 DNS，可向固定可信的 HTTPS DNS 服务取得并验证真实公网地址，仍不连接合成私网 IP。
- 单文件代码做 HTML 结构和 JavaScript 语法检查；这不保证任意需求的全部交互都自动正确，必须在预览中验证。

## 对话内定时检查

- 仅页面打开时有效，配置和运行记录都保存本地，跨标签页协调以减少重复触发。
- 每小时/每天/每周/每月/每年；默认创建时浏览器 IANA 时区，获取失败用 Asia/Shanghai。
- 月末指定日不存在时取最后一天；闰日平年取 2 月 28 日。夏令时不存在时刻按缺口顺延，重复时刻只用较早的一次。
- 每次把所属对话与预览数据作为只读参考，搜索、读取和汇报，不改代码、不发布、不创建代码版本。
- 运行中可停止；暂停/删除会中止相关请求并阻止新触发，历史保留。
- 同一对话有运行中任务时跳过；失败记录错误，下个周期继续。关闭期间错过的计划只通知、不补跑。
- 成功/失败站内通知分别开关。通知失败不能阻止结果保存。

## 发布与 Render

- 发布产物保存在服务器文件空间，内容仅包括所选 HTML、可选公开预览种子、标题及管理凭证哈希。
- 没有后端数据库、用户账号或服务端聊天记录。发布管理凭证本身保存在本地，以哈希在服务端校验更新和下线权限。
- 同一应用重新发布使用原链接，源 HTML 被替换；取消发布后返回不可访问，保留最小权限墓碑防止他人冒领链接。
- 公开访问页在隔离 iframe 内执行 HTML，不把任意 HTML 直接作为平台同源页面执行。
- Dockerfile 多阶段构建前端并运行 Python；运行进程在准备产物目录后降低权限。
- render.yaml：用户选择的免费平台方案，保留本地工作区、生成、研究、导出和页面内定时任务；不创建磁盘，暂时禁用公开应用托管。
- render-persistent.yaml：未来可选的付费 Web Service + 1 GB 持久磁盘，本次不采用、不创建付费资源。
- Render 默认文件系统重启/部署会丢失新增文件，只有付费服务能挂载持久磁盘。参见 [官方说明](https://render.com/docs/disks)。环境自动使用 [RENDER_EXTERNAL_URL](https://render.com/docs/environment-variables) 生成链接。
